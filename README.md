# Thennaval AI — Complete Project Folder

## Folder Contents
1. `thennaval-backend/` — Node.js + Express + SQLite API server with automatic Owner WhatsApp alerts, Meta Cloud API webhook bot, stock status tracking, orders, payments, and daily sales records.
2. `ThennavalAI/` — React Native (Expo) Android-only mobile app configured with `eas.json` for direct APK compilation.

## Mobile-Only Setup (No Laptop Required)
1. Extract `ThennavalAI-Project.zip` on your Android phone.
2. Upload the folders to a new GitHub repository using Chrome (Desktop Site mode).
3. Deploy `thennaval-backend` on Render.com or Railway.app (free tier) and copy your live HTTPS URL.
4. Update `API_URL` in `ThennavalAI/App.js` with your live server URL.
5. Link your GitHub repo to Expo.dev and trigger an Android APK build.
